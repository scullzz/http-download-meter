# Замер скорости скачивания

Требуется Node.js 22 или новее. В каталоге со скриптом выполните команду, подставив HTTP(S)-адрес файла. Например, можно скачать общедоступный баннер профиля:

```sh
node measure.mjs https://raw.githubusercontent.com/scullzz/scullzz/main/profile-banner.jpg
```

Скрипт последовательно выполняет 10 GET-запросов. Каждый замер начинается перед запросом и заканчивается после чтения последнего блока тела ответа. Блоки подсчитываются по мере поступления, поэтому файл не нужно целиком хранить в памяти.

- **Среднее время (мс)** — сумма длительностей запросов, делённая на 10.
- **Объём (байты)** — суммарный размер прочитанных тел ответов, без заголовков. Клиент запрашивает передачу без сжатия. Если сервер всё же применяет сжатие, учитываются распакованные байты.
- **Скорость (Мбит/с)** — общий объём в байтах × 8 / общее время в секундах / 1 000 000. Показатель включает ожидание сервера и характеризует загрузку с выбранного адреса.

При сетевой ошибке, неуспешном HTTP-статусе или превышении 60 секунд на запрос скрипт завершится с кодом 1. Итог выводится только после всех десяти успешных загрузок.
